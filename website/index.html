GOOD TO KNOW

Before you
hit play.

Is Veylo available for iPhone?

Veylo is currently an Android app. There is no iOS release.

I already have the test app. What do I do?

Export any data you want to keep, then install this official release once. The earlier test app uses a different package and does not include the updater, so the two apps may appear separately on your phone.

Where can I report a problem?

Report it in the Veylo issue tracker. Include your device, Android version, and the steps that caused the problem.

Can I see and modify the source?

Yes. The source code is available under GNU GPL version 3. Veylo is derived from Flow Android Client by A-EDev and contributors, including its FlowNeuroEngine.
